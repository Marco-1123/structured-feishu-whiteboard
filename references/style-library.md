# V4.4 Style Library

当前正式渲染器使用克制的工作汇报设计语言。风格只改变 token，不改变事实结构、页面骨架和质量门槛。

## 正式风格

- `linear-system`：默认。中性灰白背景、紫蓝主色，适合大多数工作汇报。
- `professional-blue`：飞书蓝白取向，适合业务方案和正式汇报。
- `apple-report`：更强留白和黑灰字阶，适合决策与对比。
- `stripe-data`：偏数据报告，适合指标和经营复盘。
- `vercel-precision`：黑白高对比，适合技术与系统信息。
- `feishu-status`：低饱和功能色，适合流程、状态和风险。

未在 V4 渲染器中定义的历史风格不得用于正式 V4.4 产物。

## 共同规则

- 背景、表面、主文字、次文字、边框和主色必须形成清晰层级。
- 页面只能有一个主强调色面；不能用多种颜色装饰并列关系。
- 主色用于普通信息，绿色只用于明确成功，棕红色只用于风险或警告。
- 同组指标使用一致系列色；差异色必须有可解释的语义。
- 正文保持深色浅底，禁止依赖大面积深底白字。
- 组件外框圆角不超过 8px，描边保持 1–2px。
- 风格不能掩盖信息关系。流程仍是流程，矩阵仍是矩阵，指标仍必须突出数值。

## 字阶与间距

- 页面标题：44–52px。
- 核心判断：30–34px。
- 区域标题：24–28px。
- 卡片标题：18–22px。
- 正文：16–19px。
- 指标数字：42–56px。
- 基础间距：8 / 16 / 24 / 32 / 48 / 64。

不能通过缩小字号、压缩 padding 或减小行距解决容量问题。容量不足时应重排、合并低价值重复信息或更换语义组件。
