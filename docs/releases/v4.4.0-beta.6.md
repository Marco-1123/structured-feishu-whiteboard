# V4.4.0 beta.6

Beta.6 fixes remote-install parity: the complete Skill lives at `skills/structured-feishu-whiteboard/`, so a standard tagged install receives the renderer, semantic compiler, validators, schemas, configuration and references instead of only `SKILL.md`.

## Immutable installation

```bash
npx skills add 'Marco-1123/structured-feishu-whiteboard#v4.4.0-beta.6@structured-feishu-whiteboard' --skill structured-feishu-whiteboard -g -y --copy
```

Expected result: approximately 579 files in the installed Skill. Use the fixed tag; do not install a branch, the repository root or a raw `SKILL.md`.

## Production contract

```bash
node scripts/run-whiteboard-v44.mjs --input <inventory.json> --output-dir <output-dir>
```

Delivery requires `run-manifest.json` with `pipeline: "v4.4"` and `status: "passed"`, plus a checked SVG and non-blank PNG preview. The tag is immutable and remains the latest tested production package until a later release receives its own tag.
