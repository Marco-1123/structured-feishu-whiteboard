# Historical archive

These files preserve design context, old rules, migration evidence and prior release artifacts. They are not instructions for installing or invoking the current Skill.

- `development/`: completed implementation plans and design specifications.
- `wiki/`: the former repository wiki snapshot.
- `skill-references/`: V4.3 and earlier Agent guidance removed from the installable current reference set.
- `releases/`: superseded release notes.
- `release-evidence/`: selected Feishu previews and acceptance evidence worth retaining.
- `validation/`: historical benchmark findings.
- `examples/`: superseded showcase assets.
- `source-material/`: source articles retained for provenance, not production input.

When a historical document names `scripts/run-whiteboard.mjs`, `render-whiteboard.mjs`, DSL rendering, V3, V4.1 or V4.3 as production, read it only as a record of that release. The current production contract is defined by the root README and `skills/structured-feishu-whiteboard/SKILL.md`.
