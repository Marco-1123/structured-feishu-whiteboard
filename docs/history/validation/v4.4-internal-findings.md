# V4.4 内部多样本基准结论

## 测试范围

- 共 24 个案例：18 个官方材料案例，6 个压力案例。
- 覆盖 6 类高频场景：复盘与阶段汇报、策略方案、项目计划、调研决策、产品能力、流程协作。
- 来源限定为 OpenAI 与 Anthropic 官方报告、研究文章、系统卡和产品资料。
- 每个案例均保留来源、输入事实、期望场景、关键事实清单、语义模型、表达计划、brief、SVG 和 PNG。

## 当前结果

| 指标 | 结果 |
|---|---:|
| 完整生成 | 24 / 24 |
| 场景识别准确率 | 100% |
| 关键事实覆盖 | 100% |
| 最终可见关键事实覆盖 | 100% |
| V4.3 兜底率 | 0% |
| 六类场景具备至少两种结构 | 6 / 6 |

18 个官方案例与 6 个压力案例均识别正确。压力案例 `stress-weak-conclusion` 同时包含研究证据、开放问题和复盘动作；修复后系统会优先识别标题中的开放问题与决策意图，选择调研决策场景。该案例仍保留为跨 Agent 边界测试，不降低判定标准。

## 本轮修复

1. 修正语义分类中“正文偶然出现关键词就影响场景”的问题，标题信号只读取标题。
2. 所有关键和高重要度事实必须进入表达计划；没有合适组件时进入补充证据区，不能静默丢失。
3. 置信度区分“语义不足”和“两个优秀版式接近”。后者按确定性规则选择并标记中置信度，不再错误降级到 V4.3。
4. 项目计划可根据角色数量选择时间线或泳道；产品能力可根据对比对象选择能力层级或比较结构；流程可根据责任主体选择单线流程或泳道。
5. 文本测量与校验器使用同一宽度估算，修复英文与数字混排时的出框误差。
6. 核心判断、指标标题、比较表、流程节点支持按容器换行，不再在有空间时过早省略。
7. 关键事实覆盖改为核对最终 SVG 中的完整可见文本，避免“事实编号已选中但画面中被截断”仍被判定通过。
8. PNG 预览新增尺寸、空白图和异常黑块检查，补上仅检查 SVG 结构无法发现的渲染问题。
9. 删除没有来源的占位行动；流程风险不再被自动推断为异常分支，而是按边界与保障节点表达。

## 肉眼复查结论

- 当前代表样例没有发现文字出框、组件重叠、异常黑块或被截断的关键事实。
- 指标型复盘、前后阶段、论证地图、比较表、时间线、泳道和单线流程已经能形成明显不同的阅读路径。
- 流程泳道仍偏“工程图”表达，视觉精致度低于报告型 Onepage；它可以用于 V4.4 测试，但不应宣称已经达到最终流程图质量。
- 个别稀疏样例仍会出现局部区域利用率偏低；这不会造成结构断裂，但视觉紧凑度仍有优化空间。
- 个别内容会重复出现在“核心判断”和“判断链路”中，这是当前完整性优先策略的副作用，后续可通过语义去重进一步改善。

## 独立审查

独立审查发现了自动检查与肉眼质量之间的差距：早期版本只验证事实编号是否进入 brief，没有验证最终画面是否完整显示；PNG 也缺少像素层检查。上述问题已经纳入本轮修复与回归门禁。独立审查同时指出流程图精致度和稀疏区域利用率仍未达到最终质量，因此 V4.4 继续以 beta 形式进入跨 Agent 校准，而不是直接替代 V4.3 正式版。

## 跨 Agent 校准要求

- 使用 `cross-agent-pack.json` 中的输入，不读取本目录的期望结果、既有 brief、SVG 或 PNG。
- 每个案例记录 Agent、模型、Skill 版本、耗时、飞书文档链接和预览图。
- 优先抽测 8 个代表案例，再视结果扩大到 24 个。
- 对比重点：场景分类、关键事实遗漏、结构选择、排版稳定性、飞书侧转换差异。
