# V4.4 beta.6: installation parity

## Root cause

The repository previously placed `SKILL.md` at its root. The remote Skill installer intentionally distributes only `SKILL.md` for a root-level Skill. Local development used the full repository, while other Agents installed only the written instructions and therefore improvised their own SVG, layout, and validation behavior.

This was the main reason polished local previews and cross-Agent outputs could differ dramatically even when both claimed to use the same version.

## Correction

- The complete runnable Skill now lives in `skills/structured-feishu-whiteboard/`.
- Remote installation includes `SKILL.md`, `VERSION`, scripts, schemas, configuration, references, fixtures, and checks.
- The recommended installer uses the immutable `v4.4.0-beta.6` tag with the installer's `#ref@skill` syntax, so the tag is treated as a Git ref rather than a skill-name filter.
- Cross-Agent acceptance must confirm that `VERSION`, `scripts/run-whiteboard-v44.mjs`, and `schemas/content-inventory.schema.json` exist after installation.

## Release invariant

A version is not releasable merely because its Git repository passes tests. The exact public installation command must be tested in an isolated home directory, and the installed copy must run the production test suite and a real preview render.
